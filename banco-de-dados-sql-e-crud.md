# Banco de Dados, SQL e CRUD

* **Arquitetura MVC (Model-View-Controller):** Padrão que divide a aplicação em três camadas:
  * **Model:** Gerencia regras de negócio e interação com o banco de dados.
  * **View:** Interface apresentada ao usuário final.
  * **Controller:** Recebe requisições da View e aciona as regras no Model.
* **CRUD:** Quatro operações básicas de banco de dados: **Create** (criar/cadastrar), **Read** (ler/consultar), **Update** (atualizar/editar) e **Delete** (excluir/remover).
* **SQL (Structured Query Language):** Linguagem usada para consultar e manipular dados em banco de dados relacional.
* **Tabela:** Estrutura de banco de dados relacional que organiza informações em linhas e colunas.
* **Registro:** Conjunto de valores armazenados em uma linha de uma tabela, representando uma ocorrência de determinada entidade.
* **Chave Primária (Primary Key):** Campo ou conjunto de campos que identifica unicamente cada registro de uma tabela.
* **Chave Estrangeira (Foreign Key):** Campo ou conjunto de campos que referencia uma chave de outra tabela, permitindo relacionar registros e manter a integridade dos dados.
* **Relacionamento:** Associação lógica entre tabelas, como um para um, um para muitos ou muitos para muitos.
* **WHERE:** Cláusula SQL utilizada para filtrar registros de acordo com uma condição.
* **JOIN:** Operação SQL utilizada para combinar dados de duas ou mais tabelas relacionadas.
* **SELECT:** Comando SQL utilizado para consultar dados.
* **INSERT:** Comando SQL utilizado para inserir registros em uma tabela.
* **UPDATE:** Comando SQL utilizado para atualizar registros existentes.
* **DELETE:** Comando SQL utilizado para excluir registros de uma tabela.
* **Paginação:** Técnica de dividir um grande conjunto de dados em páginas menores, por exemplo, exibir 10 registros por página.
* **Preview de Imagem:** Funcionalidade de interface que exibe a imagem selecionada antes de enviá-la e salvá-la no servidor ou banco de dados.
