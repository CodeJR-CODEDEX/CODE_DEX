# Básicos da Programação

* [**Front-End**](https://aws.amazon.com/pt/compare/the-difference-between-frontend-and-backend/)**:** Parte visual e interativa de uma aplicação web ou mobile com a qual o usuário interage diretamente.
* [**Compilador**](https://www.ibm.com/br-pt/think/topics/compiler)**:** Programa que traduz código-fonte para outra representação executável ou intermediária, como código de máquina ou bytecode, de acordo com a linguagem e o ambiente.
* [**Interpretador**](https://coddy.tech/glossary/pt/interpreter)**:** Programa que executa código-fonte ou uma representação intermediária por meio de um mecanismo de interpretação, conforme as regras da linguagem.
* **Back-End:** Camada interna do sistema responsável pelo processamento de dados, regras de negócio e comunicação com o banco de dados.
* [**Full-Stack**](https://aws.amazon.com/pt/what-is/full-stack-development/)**:** Termo usado para descrever atuação que abrange tanto o desenvolvimento Front-End quanto o Back-End.
* [**Algoritmo**](https://pt.wikipedia.org/wiki/Algoritmo)**:** Sequência finita de instruções lógicas e bem definidas para solucionar um problema ou realizar uma tarefa.
