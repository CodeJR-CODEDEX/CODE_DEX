# Básicos da Programação

* **Front-End:** Parte visual e interativa de uma aplicação web ou mobile com a qual o usuário interage diretamente.
* **Compilador:** Programa que traduz código-fonte para outra representação executável ou intermediária, como código de máquina ou bytecode, de acordo com a linguagem e o ambiente.
* **Interpretador:** Programa que executa código-fonte ou uma representação intermediária por meio de um mecanismo de interpretação, conforme as regras da linguagem.
* **Back-End:** Camada interna do sistema responsável pelo processamento de dados, regras de negócio e comunicação com o banco de dados.
* **Full-Stack:** Termo usado para descrever atuação que abrange tanto o desenvolvimento Front-End quanto o Back-End.
* **Algoritmo:** Sequência finita de instruções lógicas e bem definidas para solucionar um problema ou realizar uma tarefa.
