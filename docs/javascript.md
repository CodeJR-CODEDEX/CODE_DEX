# JavaScript

*
  * **Variáveis (`var`, `let` e `const`):** Formas de declarar e armazenar valores no código. `let` e `const` têm escopo de bloco e são as mais recomendadas; `const` não permite reatribuição.
  * **Tipos de dados:** Categorias de valores que a linguagem reconhece, como string, number, boolean, null, undefined, objeto e array.
  * **Operadores:** Símbolos que realizam operações sobre valores, como aritméticos (`+`, `-`), de comparação (`===`, `>`) e lógicos (`&&`, `||`, `!`).
  * **Condicionais:** Estruturas como `if`, `else` e `switch` que executam trechos de código diferentes conforme uma condição seja verdadeira ou falsa.
  * **Laços de repetição:** Estruturas como `for`, `while` e `for...of` que repetem um bloco de código enquanto uma condição for atendida ou para cada item de uma coleção.
  * **Funções:** Blocos de código reutilizáveis que podem receber parâmetros e retornar um valor, declaradas com `function` ou como funções de seta (arrow functions).
  * **Arrays:** Listas ordenadas de valores acessados por índice, com métodos como `push`, `map`, `filter` e `find` para manipulação.
  * **Objetos:** Estruturas que agrupam dados em pares de chave e valor, usadas para representar entidades como um usuário ou um produto.
  * **Escopo:** Região do código em que uma variável pode ser acessada, podendo ser global, de função ou de bloco.
  * **JSON:** Formato de texto leve para troca de dados, baseado na sintaxe de objetos do JavaScript e muito usado na comunicação entre front-end e back-end.
  * **Assincronismo (Promises e async/await):** Mecanismos para lidar com operações que levam tempo, como requisições de rede, sem travar a execução do restante do código.
  * **Fetch API:** Interface nativa do navegador para fazer requisições HTTP a servidores e APIs, retornando uma Promise.
  * **Módulos (`import` e `export`):** Recurso que permite dividir o código em arquivos separados e compartilhar funções e variáveis entre eles.
  * **Armazenamento no navegador (`localStorage`):** Recurso para guardar pequenos dados no navegador do usuário de forma persistente, mesmo após fechar a página.
  * **Tratamento de erros (`try...catch`):** Estrutura para capturar e tratar erros durante a execução, evitando que o programa seja interrompido de forma inesperada.
