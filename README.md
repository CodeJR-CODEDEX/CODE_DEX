# CodeDex

Bem-vindo ao **CodeDex**, glossário de termos técnicos, siglas e conceitos recorrentes no contexto da computação e da Code Júnior.

## Objetivo

Facilitar a compreensão de termos técnicos durante o processo trainee, reduzir dificuldades decorrentes de diferentes níveis de conhecimento prévio, padronizar conceitos usados nas capacitações e incentivar a autonomia nos estudos e nas tarefas.

## Como usar

Cada verbete apresenta o termo e uma definição objetiva e acessível. Exemplos práticos e referências complementares podem ser acrescentados quando pertinentes.
