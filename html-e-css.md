# HTML e CSS

*
  * **Tags e Elementos:** Tags são as marcações escritas entre `<` e `>`; um elemento é o conjunto formado pela tag de abertura, o conteúdo e a tag de fechamento.
  * **Atributos:** Informações adicionais declaradas dentro da tag de abertura, como `id`, `class`, `href` e `src`, que configuram o comportamento ou a identificação do elemento.
  * **HTML Semântico:** Uso de tags que descrevem o significado do conteúdo, como `header`, `nav`, `main`, `section`, `article` e `footer`, em vez de `div` genéricas, melhorando a organização e a acessibilidade.
  * **Formulários:** Conjunto de elementos como `form`, `input`, `label`, `select` e `button` que permitem ao usuário inserir e enviar dados para a aplicação.
  * **Links e Imagens:** Elementos `a` e `img` usados para navegar entre páginas e exibir imagens, sendo importante preencher o atributo `alt` nas imagens para descrevê-las.
  * **Acessibilidade:** Prática de construir interfaces que possam ser utilizadas por todas as pessoas, incluindo quem usa leitores de tela ou navega pelo teclado, por meio de semântica, contraste adequado e textos alternativos.
  * **Seletores CSS:** Padrões que indicam a quais elementos HTML uma regra de estilo será aplicada, como seletores de tag, de classe (`.classe`), de id (`#id`) e de atributo.
  * **Pseudo-classes:** Seletores que aplicam estilos conforme o estado do elemento, como `:hover`, `:focus` e `:nth-child()`.
  * **Especificidade e Cascata:** Regras que definem qual estilo prevalece quando várias declarações atingem o mesmo elemento, considerando o tipo de seletor, a ordem no código e o uso de `!important`.
  * **Box Model:** Modelo que descreve cada elemento como uma caixa composta por conteúdo, `padding`, `border` e `margin`.
  * **Display:** Propriedade que define como um elemento se comporta no fluxo da página, com valores como `block`, `inline`, `inline-block`, `flex`, `grid` e `none`.
  * **Position:** Propriedade que controla o posicionamento de um elemento, com valores como `static`, `relative`, `absolute`, `fixed` e `sticky`.
  * **Variáveis CSS (Custom Properties):** Valores reutilizáveis declarados com `--nome` e acessados com `var(--nome)`, úteis para centralizar cores, espaçamentos e fontes.
  * **Media Queries:** Regras CSS aplicadas apenas quando determinadas condições são atendidas, como a largura da tela, permitindo implementar os breakpoints do layout responsivo.
  * **Mobile First:** Abordagem em que o layout é planejado e estilizado primeiro para telas pequenas e depois ampliado para telas maiores por meio de media queries.
  * **Transições e Animações:** Recursos do CSS (`transition` e `@keyframes`) que suavizam mudanças de estilo e criam movimentos sem necessidade de JavaScript.
